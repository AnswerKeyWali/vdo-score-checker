📘 Rajasthan VDO Exam Score Checker (2025)

A web-based tool to calculate and store marks for the Rajasthan VDO (Village Development Officer) 2025 offline exam, following the official marking scheme.
Built using HTML, CSS, JavaScript, and Google Sheets (via Apps Script) — hosted free on GitHub Pages.

🚀 Features

🧾 Candidate detail form (Name, Roll No, Category, etc.)

📄 All 160 questions displayed with 5 options (A–E)

🖊️ Students select answers just like filling an OMR sheet

⚖️ Auto-calculates marks using official VDO marking rules:

Correct answer → +1.25 marks

Wrong answer → −0.4167 marks (1/3 negative)

Option E (Skipped) → 0 marks

Blank (no option selected) → −0.4167 marks (negative)

💾 Auto-saves responses locally in the browser

📤 Submits results to Google Sheets for leaderboard creation

🖨️ Printable individual score report

💡 Works entirely offline (except when saving to Google Sheet)
